The token system — small, fixed, ruled

This is the actual cure. Today there are ~6 ad-hoc greys and two kinds of border. The Linear look is 4 surfaces, 2 hairline weights, 3 text tiers, 1 accent — and rules about when each is allowed. Nothing in the app gets a color that isn't on this page.

Surfaces — 4 elevations, nothing between

canvas #08090a
app bg · the gap between floating panels · inset field wells
surface #131417
the floating panel card body · active tab shares this
raised #1b1c1f
cards / tiles / inputs sitting on a surface
raised-hover #232427
hover state for raised things & menu items

Hairlines — translucent white, exactly 2 weights (the Linear signature)

hairline rgba(255,255,255,.07) — every default border: panels, cards, fields, dividers
hairline-strong rgba(255,255,255,.12) — hover/emphasis, resizer, ghost-button edge

Text — 3 tiers only

text-1 primary #ededef
text-2 secondary / labels #9b9ba4
text-3 faint / placeholder #62626b

Accent — fire orange, rationed

accent #f0641e
accent-hover #ff7a33
accent-text #ff8a4d
selection tint rgba(240,100,30,.14)
success #3ec28b
danger #f0574d

The rules (this is what kills the AI-generated look)

1. 4 surfaces, full stop. No component invents a 5th grey. Elevation goes canvas → surface → raised → raised-hover, never sideways.
2. Every border is a hairline (one of the two white-alpha weights). No more `#283039` / `#313a47` hex borders.
3. Accent is rationed: active-tab underline · focus ring · selected row · and exactly one primary button per view. Everything else (Delete, secondary actions) is a ghost button. Orange is never decoration.
4. 3 text tiers only. Labels are text-2 uppercase; placeholders text-3.
